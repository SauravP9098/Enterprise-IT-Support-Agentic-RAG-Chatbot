# KB03 - Outlook is not opening

## Purpose
This KB provides troubleshooting steps when Outlook is not opening.

## Steps

### Step 1: Verify Internet Connectivity
- Ensure the user has a stable internet connection.
- Restart the router or modem.
- If using Wi-Fi, move closer to the router or connect directly using a LAN/Ethernet cable.

### Step 2: Clear Cache and Temporary Files
- Clear browser cache and cookies.
- Press **Win + R**.
- Type **temp** and press Enter.
- Delete all temporary files.

### Step 3: Verify Global Protect Connection
- Check if **Global Protect VPN** is connected.
