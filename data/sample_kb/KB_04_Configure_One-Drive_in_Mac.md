# KB04 - One Drive Configuration on macOS

## Purpose
This KB provides the steps to configure and set up OneDrive on macOS after the Workspace Hub configuration is completed.

## Steps

### Step 1: Verify OneDrive Installation
- After Workspace Hub configuration, Microsoft applications (OneDrive, Excel, Teams, and other Office apps) are installed automatically.
- Verify that OneDrive is installed by navigating to:
  - Finder → Applications → OneDrive

### Step 2: Launch OneDrive
