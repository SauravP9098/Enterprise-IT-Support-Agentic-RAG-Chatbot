# KB02 - Global Protect Issue

## Purpose
This KB provides troubleshooting steps for authentication, connectivity, and application issues related to Global Protect. 

## Steps

### Step 1: Verify User Credentials
- Ensure the user is entering the correct login credentials.
- The user should use their email ID and current login password. 

### Step 2: Authentication Failed Error
- If Global Protect displays **"Authentication failed"** after entering credentials:
  - Reset the user's password through the ARS portal.
  - Retry logging in with the updated password. 

### Step 3: Network Connection Unreachable
- Verify that the user has a stable internet connection.
- Restart the router or modem.
- If using Wi-Fi, move closer to the router or connect using an Ethernet cable. 

### Step 4: Clear Temporary Files
- Press **Win + R**.
- Type **temp** and press Enter.
- Delete all temporary files. 

### Step 5: Refresh Global Protect
- Refresh the Global Protect application and attempt the connection again. 

### Step 6: Repair Global Protect
- Open **Global Self-Service Toolkit** from Windows Search.
- Use the repair option to fix the Global Protect application if it is not functioning properly.

## Expected Outcome
Global Protect should successfully authenticate and establish a connection after completing the troubleshooting steps above.
